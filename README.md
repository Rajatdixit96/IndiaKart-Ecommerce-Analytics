# IndiaKart E-Commerce Data Analytics

## Project Overview

IndiaKart E-Commerce Data Analytics is an end-to-end data analytics project focused on analyzing e-commerce sales, customer behavior, product categories, payments, returns, operations, and inventory performance.

The project follows a structured analytics workflow from data cleaning and exploratory analysis to KPI calculation, Power BI dashboard development, and management reporting.

## Project Objectives

- Clean and validate e-commerce datasets
- Perform Exploratory Data Analysis (EDA)
- Calculate key business KPIs
- Analyze revenue and order performance
- Understand customer segments and lifetime value
- Analyze category and payment performance
- Evaluate cancellations, returns, and inventory
- Build an interactive Power BI dashboard
- Prepare a management summary report

## Project Phases

### Phase 1 — Data Cleaning
- Data quality checks
- Missing value analysis
- Data type validation
- Duplicate and consistency checks
- Preparation of analysis-ready datasets

### Phase 2 — Exploratory Data Analysis
- Revenue and order analysis
- Category performance
- Customer analysis
- Payment method analysis
- Product and rating analysis
- Operational analysis
- Visual exploration of business trends

### Phase 3 — KPI Analysis

The project calculates key business KPIs including:

- Gross Merchandise Value (GMV)
- Net Revenue
- Average Order Value (AOV)
- Cancellation Rate
- Return Rate
- Customer Lifetime Value (CLV)
- Month-over-Month (MoM) Growth
- Top Category Revenue Share
- Payment Failure Rate
- Inventory Fill Rate

### Phase 4 — Power BI Dashboard

The Power BI dashboard provides interactive analysis across:

- Revenue Overview
- Category Performance
- Customer Insights
- Operations
- Inventory Analysis

## Key Business Insights

- Electronics contributes the highest revenue share at approximately 57.41%.
- Sports & Fitness is the second-highest revenue-generating category at approximately 17.38%.
- Premium customers have the highest average Customer Lifetime Value.
- Cancellation and return rates require monitoring against the defined business benchmarks.
- Payment failure rate is an area that can be monitored to improve successful transaction completion.
- Inventory Fill Rate is approximately 99.80%.
